# 골프 스코어 웹 도구

골프 스코어 앱(폰 + Wear OS)의 **백업 파일**을 PC·태블릿 브라우저에서 열어 골프장과 지난 라운드를 고치는 도구.
폰으로는 고치기 어려운 기존 기록을 정리하는 보조 도구다.

- 서버가 없다. 파일은 **이 브라우저 안에서만** 열고 고치고 저장한다. 어떤 서버로도 보내지 않는다
- 이 저장소에는 가짜 예시만 있다(`examples/`). 내 백업 파일은 커밋하지 않는다

## 쓰는 순서
1. 폰: 라운드 탭 ⋮ → **백업 파일로 저장 (JSON)** → Google Drive 등
2. 웹 도구: **백업 파일 열기** → 골프장·라운드 고치기 → **저장** 탭에서 백업 파일로 저장
3. 폰: 라운드 탭 ⋮ → **백업 파일 가져오기** → 고친 것만 들어간다(수정 시각이 더 최신인 것만, 폰 기록은 지우지 않음)

## 할 수 있는 것 (v1)
- 골프장: 이름, 9홀 코스(1st 코스, 2nd 코스 …: 코스 이름, 스코어카드 모양의 홀별 파·HCDP 칸, 9홀 코스 레이팅·슬로프), 9홀 코스 추가, 새 골프장
  - 칸에서 엔터를 누르면 다음 홀로, "4,4,3,5…" 를 붙여 넣으면 오른쪽 칸으로 나눠 채움
  - 라운드에 코스를 지정할 때 라운드 레이팅·슬로프가 비어 있으면 9홀 값의 합·평균(WHS)으로 채움(앱 1.8 이상 필요)
- 라운드: 이름·날짜·메모·진행 중·레이팅·슬로프·홀별 HCDP, 전반·후반 코스 지정, 홀별 파·타수·퍼팅·벌타·페어웨이·GIR
- 여러 라운드 한꺼번에: 골프장·코스 지정, 이름 바꾸기
- 작업 중인 내용은 브라우저에 임시 보관(창을 닫아도 이어서 하기)

하지 않는 것: 골프장·라운드 삭제(폰에서), 샷 기록 고치기(보기만)

## 개발
빌드 없는 HTML + 자바스크립트(ES 모듈) + CSS. 라이브러리 없음.

| 파일 | 내용 |
|---|---|
| `js/model.js` | 계산 규칙. 앱 `shared` 모듈의 규칙을 그대로 옮긴 것(앱과 함께 바꾼다) |
| `js/backup.js` | 백업 v2 열기·검사·바뀐 것 찾기·저장(고친 항목만 `updatedAt` 을 올림) |
| `js/app.js` | 화면 |
| `js/draft.js` | 브라우저 임시 보관(IndexedDB) |
| `tools/make-sample.mjs` | 예시 백업 파일 만들기 |

```bash
npm test
```
```bash
node tools/make-sample.mjs
```
```bash
python -m http.server 8765
```
(브라우저에서 http://127.0.0.1:8765 . ES 모듈이라 파일을 바로 열면 동작하지 않는다)

예시 파일(`examples/*.json`)을 다시 만들면 앱 저장소 `shared/src/test/resources/web/` 에도 복사한다.
앱의 `WebToolBackupTest` 가 그 파일을 읽어 앱이 그대로 읽는지, 가져오면 고친 것만 들어가는지 확인한다.

기능 정의: 앱 저장소 `docs/spec-web-tool.md`
