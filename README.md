# 골프 스코어 웹 도구

골프 스코어 앱(폰 + Wear OS)의 **백업 파일**을 PC·태블릿 브라우저에서 열어 골프장·야디지북과 지난 라운드를 고치는 도구.
폰으로는 고치기 어려운 기존 기록을 정리하고, 골프장 공식 홈페이지 자료로 야디지북을 만드는 보조 도구다.

- 서버가 없다. 파일은 **이 브라우저 안에서만** 열고 고치고 저장한다. 어떤 서버로도 보내지 않는다
- 이 저장소에는 가짜 예시만 있다(`examples/`). 내 백업 파일과 골프장 그림은 커밋하지 않는다

## 쓰는 순서
1. 폰: 라운드 탭 ⋮ → **백업 파일로 저장 (JSON)**, 야디지북 그림이 있으면 **(그림 포함 zip)** → Google Drive 등
2. 웹 도구: **백업 파일 열기**(.json·.zip) → 골프장·야디지북·라운드 고치기 → **저장** 탭에서 백업 파일로 저장(그림을 넣었으면 zip)
3. 폰: 라운드 탭 ⋮ → **백업 파일 가져오기** → 고친 것만 들어간다(수정 시각이 더 최신인 것만). 웹에서 지운 것은 폰이 목록을 보여 주고 물어본 뒤 지운다

저장하는 파일은 백업 v3 라 **폰 앱 1.9 이상**이 필요하다.

## 할 수 있는 것
- 골프장: 이름, 9홀 코스(1st 코스, 2nd 코스 …: 코스 이름, 스코어카드 모양의 홀별 파·HCDP·티별 거리 칸, 9홀 코스 레이팅·슬로프), 9홀 코스 추가, 새 골프장, 지우기
  - 칸에서 엔터를 누르면 다음 홀로, "4,4,3,5…" 를 붙여 넣으면 오른쪽 칸으로 나눠 채움
  - 라운드에 코스를 지정할 때 라운드 레이팅·슬로프가 비어 있으면 9홀 값의 합·평균(WHS)으로 채움(앱 1.8 이상 필요)
- 야디지북(앱 1.9): 골프장마다 티 목록(기본 블랙·블루·화이트·레드, 이름·순서 바꾸기), 티별 거리(미터, 야드로 적으면 미터로 바꿔 저장),
  홀마다 홀 지도·그린 지도·공식 공략·위험 요소·그린 메모·내 공략 메모
  - 그림 넣기: 칸에 끌어다 놓기, 칸을 누르고 Ctrl+V(화면 캡처 붙여넣기), 파일 고르기. 긴 변이 1600px 보다 크면 1600px 로 줄이고 작으면 원본 크기(JPEG)
  - 여러 장 한꺼번에: 파일 이름을 `코스이름_홀번호_hole.jpg` / `코스이름_홀번호_green.jpg` 로 저장해 두고 끌어다 놓기
- AI 결과 붙여넣기: 골프장 탭 [프롬프트 복사] 로 AI 에게 줄 프롬프트를 받고, AI 답(`golfscore-club/1` JSON)을 [AI 결과 붙여넣기] 에 넣으면
  골프장 편집 화면에 9홀 코스·파·HCDP·레이팅·티별 거리·공략이 채워짐(저장 전에 확인). 그림은 주소 목록대로 저장해 끌어다 놓기. 예시: `examples/sample-club.json`(가짜 골프장)
- 라운드: 이름·날짜·메모·진행 중·레이팅·슬로프·홀별 HCDP, 전반·후반 코스 지정, 홀별 파·타수·퍼팅·벌타·페어웨이·GIR, 지우기
- 여러 라운드 한꺼번에: 골프장·코스 지정, 이름 바꾸기
- 지운 것은 저장 전까지 [저장] 탭에서 되돌리기
- 작업 중인 내용(그림 포함)은 브라우저에 임시 보관(창을 닫아도 이어서 하기)

하지 않는 것: 샷 기록 고치기(보기만), 골프장 홈페이지 직접 읽기·그림 자동 내려받기

## 개발
빌드 없는 HTML + 자바스크립트(ES 모듈) + CSS. 라이브러리 없음.

| 파일 | 내용 |
|---|---|
| `js/model.js` | 계산 규칙. 앱 `shared` 모듈의 규칙을 그대로 옮긴 것(앱과 함께 바꾼다) |
| `js/backup.js` | 백업 v2·v3(.json·.zip) 열기·검사·바뀐 것 찾기·지우기·저장(고친 항목만 `updatedAt` 을 올림) |
| `js/zip.js` | zip 쓰기(묶기만)·읽기(묶기만·deflate) |
| `js/images.js` | 그림 줄이기·JPEG 로 바꾸기(브라우저 전용) |
| `js/app.js` | 화면 |
| `js/draft.js` | 브라우저 임시 보관(IndexedDB) |
| `tools/make-sample.mjs` | 예시 백업 파일 만들기(가짜 골프장·직접 그린 가짜 그림) |

```bash
npm test
```
```bash
node tools/make-sample.mjs
```
```bash
python -m http.server 8765
```
(브라우저에서 http://127.0.0.1:8765 . ES 모듈이라 파일을 바로 열면 동작하지 않는다)

예시 파일(`examples/*.json`, `examples/*.zip`)을 다시 만들면 앱 저장소 `shared/src/test/resources/web/` 에도 복사한다.
앱의 `WebToolBackupTest` 가 그 파일을 읽어 앱이 그대로 읽는지, 가져오면 고친 것만 들어가는지 확인한다.
